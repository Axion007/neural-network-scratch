# Neural Network From Scratch

## Overview
A fully implemented feedforward neural network built from scratch using only NumPy. No external ML libraries!

## Architecture
- 2 input neurons
- 4 hidden neurons
- 1 output neuron
- Sigmoid activation function
- Backpropagation algorithm

## Features
- ✅ Forward propagation
- ✅ Backward propagation (Backprop)
- ✅ Sigmoid activation
- ✅ Gradient descent optimization
- ✅ XOR problem solver

## Implementation Details
- Weights initialized randomly (small values)
- Biases initialized to zero
- Binary cross-entropy loss
- Gradient descent with configurable learning rate
